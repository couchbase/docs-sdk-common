// tag::virtual[]
==== Platforms, Chipsets, and Virtual Environments

Couchbase Server can be expected to run on modern ARM chips, and virtualised platforms (such as Microsoft Hyper-V). 
Nevertheless, there are so many products available that not all can be tested --
as such, we do not call out specific support for any particular product.
Please contact our support organisation if you run into any issues.
